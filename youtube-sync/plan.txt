# ============================================================
#  خطة مزامنة قنوات يوتيوب مع أقسام الموقع
# ============================================================
#  القواعد:
#   - السطر الذي يبدأ بـ # هو تعليق ويُتجاهل.
#   - اسم القسم بين أقواس مربعة، مثل:  [رياضة]
#   - لقسم فرعي استخدم > مثل:  [رياضة > كرة القدم]
#   - تحت كل قسم اكتب القنوات، قناة في كل سطر، بأي صيغة:
#         @اسم_القناة
#         https://www.youtube.com/@اسم_القناة/playlists
#         https://www.youtube.com/channel/UCxxxxxxxxxxxxxxxxxxxxxx
#   - إذا القسم غير موجود في الموقع يُنشأ تلقائياً.
#   - القناة تظهر بالقسم، وقوائمها وفيديوهاتها تُجلب داخل الموقع.
#   - السكربت يضيف ولا يحذف: حذف سطر من هنا لا يحذف القناة من الموقع.
#
#  مثال (احذف # لتفعيله):
#
#  [رياضة]
#  @GoogleDevelopers
#  https://www.youtube.com/@Google/playlists
#
#  [أطفال > أناشيد]
#  @YouTube
# ============================================================
